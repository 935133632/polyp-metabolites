# Publication package

Plasma NMR metabolomic profiles and incident colon and stomach/duodenal polyps: a prospective analysis of 274,260 UK Biobank participants.

Everything is generated by `code/20_build_publication_package.py` from the analysis results; rerun it after any change to the manuscript text, tables or figures.

| Folder | Content |
|---|---|
| `01_Manuscript/Manuscript.docx` | Title, abstract, main text, declarations, references (43), Table 1, Table 2 and figure legends |
| `02_Figures/Main/` | Main figures (Fig. 1-10; panels A/B/C as separate files), vector PDF and 300-dpi PNG |
| `03_Tables/` | Table 1 (baseline characteristics) and Table 2 (key metabolites across adjustment models) as Word and Excel |
| `04_Supplementary/Supplementary_Information.docx` | Supplementary figure legends and figures (S1-S9) and the index of supplementary tables |
| `04_Supplementary/Supplementary_Tables.xlsx` | Supplementary tables S1-S5 (S1 metabolite-level results incl. annotation, S2 prediction, S3-S4 specificity, S5 lipid audit) |
| `04_Supplementary/Supplementary_Figures/` | Supplementary figures as vector PDF and PNG |
| `05_References/` | `references.ris` (EndNote/Zotero import) and `references.csv`; the same 43 items are in the Zotero collection `polyp_metabolites` |
| `06_Code_and_results/` | Code and aggregate results (no individual-level data); the repository is https://github.com/935133632/polyp-metabolites |
| `SUBMISSION_CHECKLIST.md` | Items to complete before submission |

Individual-level UK Biobank data are not part of the package.
